Política de privacidad

Última actualización: 15 de octubre de 2026.

Jarvis YouTube es una herramienta privada que usa únicamente su propietario para subir y administrar videos en sus propios canales mediante la API de YouTube.

Datos que usa

Solo accede a la cuenta de YouTube de su propietario, con su autorización, para subir videos, editar sus datos y leer estadísticas de sus canales. No accede a datos de otras personas.

Cómo se guardan

Los permisos de acceso se guardan de forma cifrada en el equipo del propietario. No se venden, no se comparten con terceros y no se usan para publicidad.

Revocar el acceso

El acceso se puede retirar en cualquier momento desde la configuración de seguridad de la cuenta de Google (Apps de terceros con acceso a la cuenta).

El uso de la información recibida de las API de Google se apega a la Política de Datos del Usuario de los Servicios de las API de Google, incluidos los requisitos de uso limitado.
